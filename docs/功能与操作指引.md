# GoFast-GoFile 功能与操作指引

## 一、工具用途

GoFast-GoFile v5.1 用于从 GoFile 下载大文件，重点解决大文件下载中断、并发连接和旧版状态迁移问题。程序优先使用 HTTP Range 分片下载；如果当前文件节点不支持分片，则自动回退到单连接断点续传。

本工具只负责下载和本地状态恢复，不提供文件上传、分享链接创建、账号管理或下载内容校验功能。

## 二、准备工作

### 环境要求

1. Windows 10 或更高版本。
2. Python 3.10 或更高版本。
3. PowerShell 或命令提示符。
4. 可访问 `https://gofile.io` 和 `https://api.gofile.io` 的网络。
5. 一个 GoFile 内容链接，例如 `https://gofile.io/d/XXXXXX`。

如果只使用已构建的 `dist\GoFast-GoFile-v5.1.exe`，运行下载时不需要单独安装 Python；构建程序仍需要 Python 和 `pyinstaller`。

### 安装依赖

在项目根目录执行：

```powershell
py -m pip install -r requirements.txt
```

若要构建单文件程序，执行：

```powershell
.\build_exe.bat
```

构建产物为 `dist\GoFast-GoFile-v5.1.exe`。`dist`、`build` 和 `*.spec` 已加入 Git 忽略规则，不应提交到仓库。

## 三、下载功能

### Python 入口

```powershell
py .\gofast.py download "https://gofile.io/d/XXXXXX" --out "D:\Download"
```

### 可执行文件入口

```powershell
.\dist\GoFast-GoFile-v5.1.exe download "https://gofile.io/d/XXXXXX" --out "D:\Download"
```

### 参数说明

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `url` | 无 | GoFile 内容链接，必填 |
| `--out` | `downloads` | 最终文件保存目录 |
| `--workers` | `16` | 并发连接数，程序限制在 `1` 到 `64` |
| `--auto-workers` | 关闭 | 先测速，再从预设并发数中选择一个值 |
| `--segment-mib` | `64` | 每个分片大小，最小为 `8 MiB` |
| `--retries` | `8` | 单个分片失败后的最大尝试次数 |
| `--password` | 无 | 私有或加密内容的密码 |

示例：

```powershell
# 使用 32 个连接下载到指定目录
.\dist\GoFast-GoFile-v5.1.exe download "https://gofile.io/d/XXXXXX" --workers 32 --out "D:\Download"

# 自动测速选择并发数，并设置每片 128 MiB
.\dist\GoFast-GoFile-v5.1.exe download "https://gofile.io/d/XXXXXX" --auto-workers --segment-mib 128

# 下载需要密码的内容
.\dist\GoFast-GoFile-v5.1.exe download "https://gofile.io/d/XXXXXX" --password "你的密码"
```

如果内容包含多个文件，程序会列出文件并要求输入编号。多连接模式完成后，临时状态目录会在可以清理时自动删除；如果目标位置已有同名文件，旧文件会先改名为 `<文件名>.old`。单连接回退模式会直接替换目标文件。

## 四、断点续传与状态文件

多连接下载的状态目录位于最终文件旁边，命名格式为：

```text
.gofast_v5_<文件名>\
  manifest.json
  <文件名>.partial
```

下载中断时不要删除该目录或 `.partial` 文件。重新执行原下载命令即可继续。`manifest.json` 记录总大小、目标路径、分片范围和每片已完成字节数；`.partial` 是预分配的临时文件。

服务器不支持 `206 Partial Content` 时，程序会使用 `<文件名>.part` 进行单连接续传。除非确认不再需要续传，否则不要删除这些状态文件。

## 五、v1/v2 状态迁移

迁移用于把旧版 GoFast 已经下载的 `.part` 分片接入 v5。迁移前必须：

1. 关闭旧版 GoFast 下载进程。
2. 确认 v1/v2 工作目录中存在 `manifest.json` 和分片文件。
3. 在 v5 正常继续下载并确认文件可用前，不要删除旧版目录。

使用批处理入口：

```powershell
.\handoff_v2_to_v5.bat
```

或直接执行：

```powershell
.\dist\GoFast-GoFile-v5.1.exe migrate-v2 --v2-dir "D:\旧版下载\.gofast_xxx"
```

可选参数：

```powershell
.\dist\GoFast-GoFile-v5.1.exe migrate-v2 `
  --v2-dir "D:\旧版下载\.gofast_xxx" `
  --v5-dir "D:\新版状态\.gofast_v5_文件名" `
  --name "文件名.zip"
```

迁移会创建一个 v5 `.partial` 和新的 `manifest.json`，并按照旧版清单中的偏移复制现有分片。程序会检查复制前后的分片大小和修改时间；发现旧分片仍在变化时会停止，以免生成不一致的状态。

## 六、短 `.partial` 文件修复

当 v5 启动时报告类似下面的大小不一致：

```text
v5 partial 文件大小异常: 当前大小 != 清单记录的目标大小
```

先不要删除任何 v2/v5 文件，确认状态目录和 `manifest.json` 仍然属于同一份下载，然后执行：

```powershell
.\repair_v5.bat
```

或直接执行：

```powershell
.\dist\GoFast-GoFile-v5.1.exe repair-v5 `
  --v5-dir "D:\Download\.gofast_v5_文件名.zip"
```

修复规则：

- `.partial` 比目标小：原地扩展到目标大小，已有字节保留。
- `.partial` 比目标大：拒绝操作，避免状态错配。
- 缺少 `manifest.json` 或 `.partial`：停止并报告错误，不自动猜测路径。

修复完成后，使用原来的 `download` 命令继续下载。

## 七、批处理入口

| 文件 | 用途 | 注意事项 |
| --- | --- | --- |
| `download_auto.bat` | 输入链接后自动测速 | 需要先生成 `dist\GoFast-GoFile-v5.1.exe` |
| `download_64.bat` | 输入链接后使用 `64` 并发 | 并发越高不一定越快，受节点和网络限制 |
| `handoff_v2_to_v5.bat` | 迁移旧版状态 | 旧版进程必须先停止 |
| `repair_v5.bat` | 修复短 `.partial` | 只扩展，不删除已有数据 |

## 八、常见问题

### 找不到 GoFile 内容

确认链接是 `https://gofile.io/d/XXXXXX` 格式，并检查网络是否能访问 GoFile。程序不会从任意网页地址猜测内容编号。

### 自动测速全部失败

这通常表示当前节点不支持 Range 分片或网络不稳定。可以去掉 `--auto-workers`，使用较低的 `--workers 4` 或 `--workers 8` 重试；如果服务器返回非 `206`，程序会自动尝试单连接模式。

### 迁移提示旧进程仍在运行

退出旧版 GoFast 后再重试。程序不会强制结束旧进程，也不会修改旧版下载目录。

### 修复后仍然无法继续

检查 `--v5-dir` 是否指向包含 `manifest.json` 的状态目录，并确认目标路径、目标大小和 `.partial` 属于同一份下载。不要把另一个下载任务的临时文件改名后混用。

### 下载完成后出现 `.old`

如果目标位置已有同名文件，程序会将旧文件改名为 `<文件名>.old`，再把完成的临时文件改为目标文件名。请确认新文件可用后，再由用户自行决定是否清理旧文件。

## 九、数据与安全边界

- 程序会创建临时 GoFile API 账号，用于读取内容元数据和取得下载直链。
- 账号令牌只保存在当前运行内存中，不写入仓库文件；不要在调试输出中加入令牌、密码或 Cookie。
- 下载密码通过命令行传入时，可能被本机进程查看；在共享电脑上应避免这样传递敏感密码。
- 程序不会上传本地文件，也不会删除 v1/v2 原始状态。
- 本项目不包含 GoFile 服务条款、文件版权或内容安全审查；使用者应确保拥有相应下载权限。

## 十、限制

- 仅支持 GoFile 内容下载，不支持上传。
- 依赖 GoFile API、直链和 Range 行为；服务端策略变化可能导致下载或测速失败。
- 当前没有内置下载后哈希校验；需要完整性证明时，应使用来源方提供的校验值进行外部核对。
- 当前未附带许可证文件；公开分发前应明确项目许可证和第三方依赖的合规信息。
